核对日期：2026-09-29。外部仓库 [`wy51ai/floorplan-3d`](https://github.com/wy51ai/floorplan-3d) 的 `master` 提交为 [`a03136c`](https://github.com/wy51ai/floorplan-3d/tree/a03136c86842968a3de5da4c33549d3df3313c51)。以下结论来自该提交的 README 和 `index.html` 源码静态检查，未做浏览器运行验收。本地对照基于当前 `living-room-model` 的 README 与 `src/`；不把视频估算的尺寸视为实测。

## 已有功能或暂不宜照搬

- 外部的 3D 鸟瞰/俯视、漫游、门开关、全高墙/剖切墙、日照和夜景均有相应源码。[视角与开关](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L245-L280)、[日照实现](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L2383-L2398)。本项目已经具备相近视角、漫游、门窗开合和光照滑块；外部日照角度仅由时间滑块和固定三角函数计算，源码没有经纬度、日期或房屋朝向输入，属于视觉示意，不能据此推断真实采光。
- 外部家具库在源码里恰好有 **60 个**预设条目（README 写“60 余种”），通过类型/默认尺寸/颜色生成程序化 3D 家具。[家具库](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L461-L494)、[建模函数](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L1777-L2259)。本项目当前重点是与实物型号、视频证据相符的沙发和固定装潢；通用几何家具可用于占地试摆，不能当作精确商品模型。
- “拆改墙体”通过切换预先写在 `WALLS` 中的整段非承重墙的 `demolished` 状态实现；承重墙拒绝拆改。房间多边形、门窗洞和家具目录均是写死的常量，**不支持用户导入户型图片/CAD 并自动识别，也不是自由画墙编辑器**。[户型常量](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L384-L460)、[墙体切换](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L1078-L1085)。本项目没有可靠的完整建筑测量数据，先不把此功能当施工依据。

## 实现边界与许可

- 外部项目源码只有 `.gitignore`、`README.md`、`index.html`，无 LICENSE 文件；README 也未声明许可证。[仓库文件列表](https://github.com/wy51ai/floorplan-3d/tree/a03136c86842968a3de5da4c33549d3df3313c51)、[README](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/README.md)。可以借鉴交互和产品思路；若复制源码、家具几何或样式进本项目，应先取得作者许可或等待明确许可。[GitHub 许可说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)。
- 该项目是单个约 2664 行的 `index.html`，Three.js 从 jsDelivr CDN 加载；首次进入 3D 要联网。仓库内未见测试、打包配置或独立资产目录。[仓库树](https://github.com/wy51ai/floorplan-3d/tree/a03136c86842968a3de5da4c33549d3df3313c51)、[CDN import map](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L216-L220)。
- 撤销栈是页面内存，刷新后仅恢复最后保存的方案；JSON 仅保存方案状态，不含户型几何。[历史与状态](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L531-L567)、[导出 JSON](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L1463-L1469)。
- 对外导出入口只有方案 JSON 和 PNG（2D/3D），源码未提供 GLB/GLTF 导出；本项目现有 GLB 导出是自身优势。[文件菜单](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L282-L290)、[导出实现](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L1378-L1395)、[3D 截图](https://github.com/wy51ai/floorplan-3d/blob/a03136c86842968a3de5da4c33549d3df3313c51/index.html#L2657-L2661)。
