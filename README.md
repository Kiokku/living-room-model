# 客厅、主卧与封闭阳台三维户型

基于 `../IMG_6030.MOV`（客厅）、`../IMG_6031.MOV`（主卧）及用户提供尺寸和布局建立的 Three.js 示意模型。主卧位于客厅左侧，窗外是封闭阳台。

## 使用

```bash
cd living-room-model
npm ci
npm run dev
```

打开终端显示的本地地址，模型默认占满窗口。可切换轴测、俯视、主卧视角和漫游模式。右上角二维户型图在固定视角中标出观察焦点和方向，在漫游模式中标出人物位置和朝向；其下方可调东南晨光亮度，0% 为夜晚。点击客厅或主卧窗帘、房门、固定柜门和衣柜门可切换开合状态；漫游中门关闭时会阻挡行走，开启后可通过。漫游时用 WASD 行走、鼠标转向，点击空白画面可锁定鼠标，按 Esc 释放；若浏览器不支持鼠标锁定，也可按住鼠标拖动转向。可下载当前视角 PNG，或导出包含当前门窗开合状态和完整墙体与顶面的 GLB。

公开页面由 GitHub Actions 在每次推送 `main` 后构建并部署到 GitHub Pages。建模时生成的视频切片和历史 PNG/GLB 导出文件已清理，页面仍支持即时下载当前视角 PNG 和模型 GLB。

## 尺寸与布局

| 房间 | 宽度 | 长度 | 依据 |
| --- | --- | --- | --- |
| 客厅 | 350 cm | 540 cm | 用户实测 |
| 主卧 | 345 cm | 约 428 cm | 宽度为用户提供；窗边墙止于客厅侧门靠入口侧边线，长度由模型门位推算 |
| 封闭阳台 | 约 345 cm | 约 112 cm | 位于主卧窗外；外沿暂与客厅窗帘端齐平，需实测 |

主卧与客厅**入口端齐平**，主卧窗边墙在客厅侧门的靠入口侧边线截止，不再伸入门洞。两者之间的侧门按通向封闭阳台绘制；主卧窗边白门也按通向阳台绘制。阳台外窗位置和分格没有视频依据，仅为封闭空间示意。暂按客厅后窗及阳台外窗朝南、夏季上午约 9–10 点的东南侧日光（高度角约 50°）设置光照，实际朝向与时刻待确认。房间室内尺寸之和不等于建筑外轮廓尺寸；隔墙厚度仅为示意。

客厅与主卧之间的隔墙在轴测和俯视视角中同样封顶，客厅通阳台侧门上方保留墙体；仅门洞本身留空。

左侧软装编辑栏提供 NORHOR HUG 沙发示意模型：外廓 210 × 95 × 82 cm，两侧抱枕之间的可坐宽度按 160 cm 绘制。可选奶油色或浅驼色；选择后新拖入的沙发使用该颜色，已选中的沙发会立即换色。可在轴测或俯视视角拖入客厅、拖动调整位置、移除选中沙发；摆放时会避开墙体、后窗帘、门和固定柜的开启区及其他沙发。布艺、双坐垫、双靠包、侧抱枕和细黑色高脚依据用户截图近似建模；背面及内部结构无参考图。只有已放置的沙发会包含在页面 GLB 导出中。

## 视频与补充条件

- 客厅：远端通幅窗帘后为墙面窗，宽度按用户估算为该墙的约 65%（约 228 cm），两侧保留实体白墙；另有窗边左侧门、入口旁白色开放格固定柜和回字形吊顶。
- 主卧：窗边双扇窗与白门、两侧收拢窗帘、窗边空调、木色半墙、入口旁固定衣柜及回字形吊顶。视频中的小凳子是可移动物品，未纳入固定户型。
- 阳台：封闭属性来自用户补充；外窗、矮墙和地砖的形式为估算，视频未直接拍到。
- 地板和客厅窗帘贴图来自客厅视频并用于在线模型；主卧使用相同木地板与窗帘纹理作为近似，颜色受手机拍摄曝光影响。

## 精度边界

模型以米为单位：客厅地面为 3.50 × 5.40 m，长宽比约 1.54；主卧宽 3.45 m，长度约 4.28 m 仍由估算的侧门位置推算。页面的室内广角视角和中等宽度下的放大取景只改变屏幕观感，不改变房间几何尺寸或 GLB 比例。视频没有可用的镜头焦距数据，无法用单段透视画面精确校准相机视角。

客厅后窗宽度约占整面墙 65% 来自用户估算；窗台暂按 80 cm，窗上沿暂按 218 cm 绘制。四处门洞宽度现统一按用户提出的 70 cm 参照值估算，并非实测；层高 268 cm、窗户、衣柜、空调、吊顶及隔墙厚度也按视频估算。模型是用于软装推敲的比例底模；家具采购和施工前需复尺，特别是客厅后窗、门洞、主卧实际长度及阳台深度。模型参数分别位于 `src/roomModel.js` 的 `ROOM` 和 `src/bedroomModel.js` 的 `BEDROOM`。
